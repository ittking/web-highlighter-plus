F1 序列化

Range → Source

将浏览器选中的 Range 对象转换为可 JSON 序列化的 Source 数据结构。fromRange() 从 Range 对象序列化，fromSelection() 从当前选区序列化。

F2 跨标签渲染

Source → DOM

将 Source 对象渲染为多个 span 包装元素。支持跨多个 HTML 标签（如 <strong>、<em>）的选区，每个标签内的文本会被独立包装。

第三段文字，包含加粗和斜体标签的混合内容。选择这段文字测试跨标签渲染。

提示： 渲染后会生成多个 span 元素（每个跨标签位置一个），但都使用相同的 data-highlight-id。

F3 类样式控制

CSS Class

为指定 ID 的高亮添加或移除 CSS 类。支持多元素高亮（跨标签时会产生多个 span），会自动应用到所有匹配的包装元素。

第四段：链接标签也会被正确处理，不会破坏原有的 HTML 结构。

第五段包含一个 code 标签 用于测试代码块的排除。

Restore

从存储的数据批量恢复高亮。使用 fromStore() 创建 Source，restore() 批量渲染。

Remove

清除单个高亮或所有高亮。remove() 移除指定 ID 的高亮，removeAll() 移除所有高亮。
