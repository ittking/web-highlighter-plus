F1 序列化

Range → Source

将浏览器选中的 Range 对象转换为可 JSON 序列化的 Source 数据结构。

方法 区别
fromRange(range) 需要手动传入 Range 对象，不会自动清除选区
fromSelection() 自动从 window.getSelection() 获取并清除选区

F2 跨标签渲染

Source → DOM

将 Source 对象渲染为多个 span 包装元素。支持跨多个 HTML 标签（如 <strong>、<em>）的选区。
